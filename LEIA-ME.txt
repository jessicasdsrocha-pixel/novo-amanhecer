PUBLICAÇÃO NO GITHUB
1. Entre no repositório novo-amanhecer.
2. Clique em Add file → Upload files.
3. Envie os 5 arquivos desta pasta, mantendo-os na raiz:
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - LEIA-ME.txt
4. Faça o commit.
5. O Vercel conectado ao GitHub deverá criar uma nova publicação automaticamente.
